## 4. [Leto: Utility-Centric Agent Memory](https://arxiv.org/abs/2611.33005)

**Authors:** Shuguang Chen, Salman Paracha  
**Categories:** cs.CL · **Published:** 2026-11-24 · **Relevance:** 9

TL;DR: Leto treats an LLM agent’s memory as a way to predict what future context will help the agent, not just a faithful record of past dialogue. It indexes conversation details and uses a utility loop to refine what is stored, improving accuracy and task completion with fewer tokens.  
Why it matters: By focusing on the usefulness of stored information, Leto boosts agent performance on personalization, long‑horizon, and long‑context tasks while keeping memory usage efficient.

## 6. [Can a Frontier LLM Repair a Quantized Network by Tool-Free Weight-Space Programming?](https://arxiv.org/abs/2611.33031)

**Authors:** Steffen Urban  
**Categories:** cs.LG, cs.AI, cs.CL · **Published:** 2026-11-24 · **Relevance:** 8

TL;DR: Front‑end LLMs can read a full 20k‑parameter CNN’s weights in text and, without any tools or data, tweak the 4‑bit quantization to recover most of the accuracy loss. For example, Opus 5.5 boosts a 4‑bit network from 60.4 % to 77.95 % by balancing rounding errors per 3×3 kernel, approaching the float baseline.  
Why it matters: It shows that large language models can perform weight‑space programming for quantized neural nets, potentially reducing the need for calibration data or specialized PTQ tools in edge deployments.

[Abstract](https://arxiv.org/abs/2611.33031) · [PDF](https://arxiv.org/pdf/2611.33031)

## 10. [Embodied AI Fails the Mirror Test: How a Simple Mirror Breaks Robot Policies](https://arxiv.org/abs/2611.33010)

**Authors:** Xuanchen Liu, Hejun Zhang, Boxuan Dong, Ying Wu +4 more  
**Categories:** cs.CV, cs.AI, cs.RO · **Published:** 2026-11-24 · **Relevance:** 7

TL;DR: A simple mirror in a robot’s workspace consistently hurts performance, dropping success rates by 10–60 % across diverse manipulation policies. The mirror causes the robot to mis‑localize objects and target their reflections, not just collide with the mirror itself.
