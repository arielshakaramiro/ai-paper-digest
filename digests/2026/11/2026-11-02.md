## 2. [Flide: Accelerating Decision Inference with Exact State Forking](https://arxiv.org/abs/2610.42148)

**Authors:** Bobo Li, Jiajia Song, Hao Fei, Wynne Hsu +1 more  
**Categories:** cs.CL · **Published:** 2026-10-30 · **Relevance:** 8

TL;DR: Flide is a new inference engine that speeds up decision‑making models by forking the logical decision tree into a single token stream, eliminating redundant recomputation and preserving exact probabilities. It can run queries up to 9.5× faster than leading engines while staying within 0.01 total variation of a float32 reference.  
Why it matters: Engineers building LLM agents can deploy Flide to achieve low‑latency, mathematically accurate decision inference without sacrificing throughput.

[Abstract](https://arxiv.org/abs/2610.42148) · [PDF](https://arxiv.org/pdf/2610.42148)

**Categories:** cs.CL, cs.AI · **Published:** 2026-10-30 · **Relevance:** 8

**Authors:** Shuyang Zhang

TL;DR: Retrieval systems that only find one tool often miss the rest of the tools an LLM agent needs, so most tested methods retrieve less than 10% of all required tools in multi‑tool queries.
