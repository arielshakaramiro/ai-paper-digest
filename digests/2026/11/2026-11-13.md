## 5. [Scale-Induced Semantic Shift in Visual Prompt Injection Against VLMs and Web Agents](https://arxiv.org/abs/2611.16744)

**Authors:** Yiheng Zhao, Runze Ji, Chenyu Yi, Yi Yu +3 more  
**Categories:** cs.AI · **Published:** 2026-11-12 · **Relevance:** 8

TL;DR: Resizing or compressing images can change what a vision‑language model “sees,” letting attackers hide instructions that only appear after aggressive downsampling. Why it matters: It shows that standard image preprocessing can create exploitable semantic gaps in VLMs, so engineers must consider scale‑consistency checks when deploying multimodal AI.

## 6. [AgentSSL: Can MLE Agents Leverage Unlabeled Data?](https://arxiv.org/abs/2611.17323)

**Categories:** cs.AI, cs.LG · **Published:** 2026-11-12 · **Relevance:** 7

TL;DR: AgentSSL treats semi‑supervised learning as a program‑search problem and shows that agents can automatically create SSL code that outperforms human‑designed baselines in most tested settings, even with very little labeled data. Why it matters: The work demonstrates that automated pipeline design can reduce the need for labeled data and manual engineering, but also highlights the critical need for better program‑selection techniques to fully realize these gains.
