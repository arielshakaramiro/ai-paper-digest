## 2. [Task-Efficient Agent Evaluation Using Cached Traces](https://arxiv.org/abs/2611.06803)

**Authors:** Ben Johnson, Hayden Helm  
**Categories:** cs.AI · **Published:** 2026-11-04 · **Relevance:** 10

TL;DR: By summarizing each agent’s execution trace with an LLM and embedding that summary, we can predict a new system’s benchmark score from just one or a few task runs, cutting error from 0.13–0.14 to 0.08–0.12.  
Why it matters: This method lets engineers quickly estimate an agent’s overall performance with far fewer full-task evaluations, speeding up development and deployment cycles.

[Abstract](https://arxiv.org/abs/2611.06803) · [PDF](https://arxiv.org/pdf/2611.06803)

## 8. [DreamRealm: Exploring and Materializing Hallucination Worlds for Trustworthy Vision-Language Models](https://arxiv.org/abs/2611.06433)

**Authors:** Benlei Cui, Chunyang Chai, Yiliang Zhang, Xiaoqian Xia +5 more  
**Categories:** cs.CV · **Published:** 2026-11-04 · **Relevance:** 8

TL;DR: DreamRealm trains vision‑language models to recognize and correct their own hallucinations by generating edited images that match the model’s mistaken responses, then re‑training the model to align responses with the correct images. Why it matters: It offers a practical, post‑training method to make multimodal LLMs more reliable in tasks that require fine‑grained visual understanding.

## 10. [Route First, See Later: Enabling Vision Agents to Reason Scientifically by Separating Routing Policy from Action Spaces](https://arxiv.org/abs/2611.06760)

**Authors:** Shubhabrata Mukherjee, Jeffrey Donatelli, Daniela Ushizima  
**Categories:** cs.CV, cs.AI · **Published:** 2026-11-04 · **Relevance:** 7

TL;DR: ZETA separates an agent’s routing decisions from the visual tools it calls, so scientists can see whether a mistake comes from choosing the wrong tool or from the tool failing. On a benchmark of 51 scientific queries, explicit routing boosted accuracy dramatically—for example, Qwen 3.8’s segmentation routing jumped from 6.2 % to 75.0 %.  
Why it matters: By isolating routing errors from perception errors, ZETA makes scientific vision agents more reliable and audit‑friendly for high‑stakes automation.

[Abstract](https://arxiv.org/abs/2611.06760) · [PDF](https://arxiv.org/pdf/2611.06760)
