## 7. [Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis](https://arxiv.org/abs/2610.37648)

**Authors:** Andrew Szot, Samira Abnar, Omar Attia, Abbas Kazerouni +4 more  
**Categories:** cs.LG · **Published:** 2026-10-27 · **Relevance:** 8

TL;DR: The paper introduces SynthAPI, a pipeline that generates synthetic tool‑use environments with controllable diversity in tools, tasks, and databases. By training 849 models on 458,752 tasks, they derive scaling laws showing that, for large data budgets, adding more tool and database variety—and increasing task complexity—yields better generalization than simply adding more tasks.  
Why it matters: These scaling laws guide efficient data collection for building robust LLM agents that can perform complex, multi‑step tasks with tools, improving performance on real‑world benchmarks.

[Abstract](https://arxiv.org/abs/2610.37648) · [PDF](https://arxiv.org/pdf/2610.37648)

## 8. [Agent-Conditioned Routing: Diverse Reasoning Paths Within One Frozen Model](https://arxiv.org/abs/2610.37375)

**Authors:** Ananth Kalyanasundaram, Ankush Kadu, Athira Gopal, Aswanth Krishnan  
**Categories:** cs.AI, cs.LG, cs.MA · **Published:** 2026-10-27 · **Relevance:** 8

TL;DR: Agent‑Conditioned Routing (ACR) lets a single frozen sparse Mixture‑of‑Experts model generate multiple, genuinely different solution paths for the same prompt, doubling the number of problems that yield at least two distinct methods compared to standard temperature sampling. It adds only a tiny 160 KiB of mask state and keeps latency and memory usage essentially unchanged.  
Why it matters: ACR enables efficient, diverse reasoning from one model copy, saving compute and simplifying deployment for AI systems that need multiple solution strategies.

[Abstract](https://arxiv.org/abs/2610.37375) · [PDF](https://arxiv.org/pdf/2610.37375)
